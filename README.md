# home-safety-sft

Учебный проект: дообучение Qwen2.5-3B-Instruct для темы «Дом и квартира».
Два эксперимента QLoRA выполнены в Google Colab на Tesla T4. Оба ухудшили
ответы относительно базовой модели.

| На 40 вопросах validation | База | SFT 1e-4 | SFT 2e-5 |
|---|---:|---:|---:|
| Ответы с повторами | 3/40 | 23/40 | 14/40 |
| Достижение лимита 512 токенов | 1/40 | 16/40 | 7/40 |
| Безопасность ChatGPT, 9 вопросов | 3,89/5 | 3,67/5 | 3,11/5 |

Полное описание работы: [отчёт PDF, 7 страниц](report.pdf) и [Markdown](report.md).
Сравнение включает 120 ответов и 27 уникальных оценок судьи. Validation
использовалась для выбора второго learning rate. На test дополнительно
проанализированы только 80 ответов базы.

## Запуск в Colab

1. Откройте [01_baseline.ipynb](notebooks/01_baseline.ipynb) в Google Colab.
   Выберите **T4 GPU** и выполните ячейки сверху вниз.
2. При запросе загрузите [home-sft-colab.zip](artifacts/home-sft-colab.zip).
   Ноутбук установит зависимости из общего `requirements.txt`, сгенерирует
   два пробных ответа и предложит скачать результаты.
3. Для обучения откройте [02_qlora_training.ipynb](notebooks/02_qlora_training.ipynb)
   в новой сессии с T4 и загрузите тот же архив.
4. Выполните проверку данных и короткое обучение. Затем включите по очереди
   `RUN_FULL_TRAINING`, `RUN_VALIDATION` и `RUN_LOWER_LR_EXPERIMENT`.
   Последняя ячейка скачивает результаты.

Нужен интернет для загрузки модели с Hugging Face. PyTorch и CUDA предоставляются
Colab, остальные зависимости находятся в одном [requirements.txt](requirements.txt).
Использованы NF4, FP16, seed 42 и жадная генерация до 512 новых токенов.
Точные настройки и версии окружения сохранены в результатах запусков.
Обновлённые ноутбуки проверены без повторной GPU-генерации; исходные обучения
и сравнение выполнены на T4.

## Данные

[Набор v1](data/v1/) содержит 80 train, 40 validation и 80 test. Данные
синтетические, на русском языке. Источники включают МЧС, МОСГАЗ, mos.ru, EPA и CDC.
Происхождение, статус проверки и SHA256 сохранены в метаданных и `manifest.json`.

Учебные записи содержат `messages` с ролями system, user и assistant.
Вопросы и критерии оценки хранятся отдельно; на вход модели поступают только
системное сообщение и вопрос. JSONL совместим с `datasets.load_dataset`.
Пользователь просмотрел 42 учебных ответа и по 8 вопросов validation/test;
независимой профессиональной экспертизы нет.

## Проверка и пересчёт результатов

Запускайте команды из корня проекта. Unit-тестам и проверке данных достаточно
стандартной библиотеки Python. Для графика нужны зависимости из requirements.txt.
Выходные каталоги должны быть новыми.

```bash
python3 -m unittest discover -s tests -v
python3 src/validate_data.py --output-dir results/repro_data
python3 src/checks.py --answers results/baseline_20261104T112446Z_7e87c62c/answers.jsonl --annotations data/safety_annotations.jsonl --examples data/safety_check_examples.jsonl --output-dir results/repro_checks
python3 src/finalize_evaluation.py --output-dir results/repro_metrics
```

Автоматическая проверка ищет предупреждение и обращение за подходящей помощью
в газовых и электрических сценариях. На 15 контрольных примерах совпадение
с разметкой - 14/15. Известная ошибка связана со сложным отрицанием опасности.
Проверка учитывает только наличие отдельных элементов, поэтому дополнена
содержательной оценкой.

Судья ChatGPT оценивал безопасность, полезность и соответствие по
[рубрике](data/judge_rubric.md). Точная версия модели неизвестна; независимой
человеческой калибровки нет. Запросы и исходные оценки сохранены в папках
`validation_judge` и `validation_judge_lr2e5` основного запуска. Для подготовки
запросов и пересчёта оценок используйте `python3 src/judge.py --help`.

## Веса

Оба адаптера сохранены в safetensors. Большие файлы исключены из Git;
их размеры, SHA256 и поля ссылок находятся в [реестре](artifacts/release_manifest.json).
Архивы подготовлены локально в `artifacts/release/`, ссылки ещё не опубликованы.
После загрузки ZIP в GitHub Release нужно добавить реальные ссылки в реестр
и проверить скачивание. Распакованная папка `adapter` передаётся параметру
`--adapter` скрипта `src/evaluate_model.py`.

Для пересборки архива Colab укажите новый файл:

```bash
python3 src/build_colab_bundle.py --output /tmp/home-sft-colab.zip
```

PDF собирается из report.md командой ниже. Нужны шрифты DejaVu Sans
и CJK-шрифт TTF для точной цитаты с китайскими символами.

```bash
python3 src/render_report.py --font-dir /path/to/dejavu --cjk-font /path/to/cjk.ttf
```
