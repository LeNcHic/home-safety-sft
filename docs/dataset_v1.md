# Набор данных v1

Синтетический русскоязычный набор для темы «Дом и квартира»: 80 учебных диалогов,
40 вопросов validation и 80 вопросов test. В каждой части равномерно представлены
восемь подтем. Источники включают МЧС, МОСГАЗ, mos.ru, EPA и CDC; ссылки
и границы их использования сохранены в метаданных.

## Формат

`train.jsonl` содержит ID, семейство сценария, тему, риск, источники, происхождение,
статус проверки и `messages` с ролями `system`, `user`, `assistant`.

`validation_questions.jsonl` и `test_questions.jsonl` содержат вопросы,
ожидаемые элементы ответа и запрещённые действия. Входами модели служат только
системное сообщение и вопрос. Файлы `*_annotations.jsonl` задают применимость
автоматической проверки отдельно от входов модели.

`scenarios.jsonl` описывает семейства сценариев, `sources.jsonl` - источники.
`manifest.json` фиксирует контрольные суммы. Замороженные файлы после обучения
не изменялись. Два test-вопроса, test_056 и test_062, принадлежат одному семейству.

```python
from datasets import load_dataset

train = load_dataset('json', data_files='data/v1/train.jsonl', split='train')
```

## Проверка качества

Проверены структура, ID, источники, точные дубли, пересечения семейств и сходство
текстов между выборками. Семейства пробных вопросов исключены из обучения
и оценочных наборов. Проверка сходства текстов не доказывает семантическую
независимость всех примеров.

Пользователь просмотрел 42 из 80 учебных ответов, включая все 17 высокого риска,
и по 8 вопросов validation/test. Остальные учебные ответы имеют авторскую проверку.
Независимая профессиональная экспертиза отсутствует. Происхождение записей
сохранено в данных и manifest.json.

Свидетельство просмотра: `results/data_v1_reviewed/human_review.json`.
Проверка источников: `results/data_v1_sources/evidence.json`.
Итоговая проверка структуры: `results/data_v1_sources/validation/validation.json`.

## Использование в эксперименте

Train использован в обоих обучениях, validation - для сравнения и выбора второго
learning rate. На test выполнен дополнительный анализ базы. Вопросы и разметка
test не использовались как учебные ответы.

Для токенизации и обучения используются `src/prepare_sft.py` и
`src/train_qlora.py`. Loss считается по ответу и токену окончания реплики;
вопрос, системное сообщение и padding маскируются. Проверенные длины учебных
последовательностей - 194-265 токенов при максимуме 1024.
