# Публикация артефактов и сдача

Отчёт содержит завершённое сравнение базы и двух адаптеров на 40 вопросах
validation. На test приведены только дополнительные результаты базы.
Оба эксперимента дообучения дали отрицательный результат.

| Материал | Путь от корня проекта |

| Отчёт, 7 страниц | report.pdf |

ZIP каждого адаптера содержит папку `adapter`, конфигурацию обучения,
окружение и `adapter_manifest.json`. После распаковки передайте папку `adapter`
параметру `--adapter` скрипта `src/evaluate_model.py`. Нужна исходная
Qwen/Qwen2.5-3B-Instruct с ревизией, указанной в README.

## Передача весов

Веса и архивы Release исключены из Git. Каждый адаптер занимает около 120 МБ,
что превышает лимит обычного GitHub-файла. Публикуйте их как вложения Release:

1. После согласования коммита и отправки кода создайте Release в репозитории.
2. Прикрепите три ZIP из `artifacts/release/`.
3. Запишите реальные ссылки в `download_url` реестра артефактов. Проверьте
   скачивание и SHA256; только после этого заполните `verified_access`
   и `access_verified_on`.
4. Добавьте проверенные ссылки в README. Для LMS используйте ссылку
   на опубликованный репозиторий и `report.pdf`.

Альтернатива Release - хранилище с доступом для преподавателей. Доступ по ссылкам
проверяется в отдельном приватном окне. До загрузки архивов поля ссылок остаются
пустыми; локальные пути и контрольные суммы уже указаны в реестре.
