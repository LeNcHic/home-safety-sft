# Дополнительная оценка базовой модели на test

Опубликованы все 80 ответов базовой модели при тех же настройках генерации,
что на validation. Папка base/ содержит вопросы, ответы, конфигурацию,
окружение и статус завершённого базового прогона.

baseline_summary.json содержит автоматические показатели базы.
baseline_qualitative_review.jsonl - дополнительный ИИ-разбор 29 ответов
на вопросы высокого риска с дословными цитатами. Независимой человеческой
или профессиональной оценки этого разбора нет.

Полные test-метрики адаптеров не получены. Их частичные ответы не входят
в публикацию и не используются для сравнения. Выводы о дообучении основаны
на завершённой validation-оценке.
